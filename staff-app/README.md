# מבט נכס — סביבת הדגמה

אתר הדגמה אינטראקטיבי לפלטפורמת בדיקות סיכון בעסקאות נדל״ן.

- מערכת צוות: תמונת מצב, רשימת תיקים, פרטי עסקה, ממצאי AI להמחשה ובקרת אנליסט.
- אזור לקוח: סטטוס בדיקה, שלבי טיפול, מסמכים ותמיכה.
- פתיחת תיק, מעבר בין המערכות ואישור ממצאים פועלים בסביבת ההדגמה.
- הנתונים אינם נשמרים. אין חיבור פעיל ל-AI, תשלומים, אימייל, העלאת מסמכים או מאגרי מידע.

הקובץ המפורסם נמצא ב-`dist/index.html`.
